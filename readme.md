Cidadão Sensor - Sarah (Defesa Civil & Clima)
Aplicativo web progressivo (PWA) de monitoramento hidrológico e climático focado na Comunidade do Sebinho (Rua Amazonas) e nas bacias do Rio Sarapuí e do Rio Dona Eugênia, em Mesquita, Rio de Janeiro. Desenvolvido para atuar como assistente inteligente de Defesa Civil em tempo real.
🚀 Funcionalidades Principais
Assistente Inteligente (Sarah): Especialista em análise de riscos climáticos e hidrológicos locais.
Alerta de Emergência Visual: Banner dinâmico de alerta máximo disparado automaticamente em situações de risco grave nas bacias monitoradas.
Voz Humanizada (Text-to-Speech): Botão de áudio integrado em cada resposta para leitura natural do texto em voz alta.
Reconhecimento de Voz (Speech-to-Text): Permite ditar mensagens por microfone para preenchimento rápido no celular.
Ajustes de Conforto Visual: Controles de tamanho de fonte (A- / A+) e Modo Noite / Dia persistente.
Segurança de Dados: Armazenamento local exclusivo da chave de API do Google AI Studio (gemini-1.5-flash), garantindo privacidade total.
📍 Área de Monitoramento
Município: Mesquita - RJ
Comunidade: Sebinho (Rua Amazonas)
Cursos d'Água Monitorados: Rio Sarapuí e Rio Dona Eugênia
⚙️ Como Configurar e Usar
Acesse o aplicativo publicado via GitHub Pages.
Na primeira execução, insira sua Chave de API do Google AI Studio no modal de configuração (ícone de chave 🔑 no topo). A chave ficará salva com segurança no seu navegador.
Digite sua dúvida, utilize o microfone 🎤 ou clique em "Ouvir Sarah" 🔊 para interagir com o sistema.
🛠️ Tecnologias Utilizadas
Frontend: HTML5, Tailwind CSS (via CDN)
Ícones: Font Awesome 6
Inteligência Artificial: Google Generative AI API (gemini-1.5-flash)
APIs Nativas: Web Speech API (Voz e Reconhecimento de Fala), LocalStorage
