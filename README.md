# 🛡️ Sarah • Defesa Civil Digital & Cidadão Sensor

Aplicativo web inteligente de monitoramento climático, telemetria comunitária e suporte desenvolvido para a **Comunidade do Sebinho (Rocha Sobrinho, Mesquita - RJ)** e o grupo **A Chave da Esperança**, atuando como ferramenta oficial do **Projeto Cidadão Sensor** na Bacia do Sarapuí.

---

## 🚀 Sobre o Projeto
A **Sarah** é uma assistente virtual humanizada e agente de monitoramento participativo estruturada como um PWA (*Progressive Web App*). Integrando a proposta do **Cidadão Sensor**, a ferramenta une tecnologia de ponta — operando com o modelo **`gemini-3.6-flash`** — com escuta empática, suporte rápido e conexão direta com dados oficiais de risco, capacitando os moradores a atuarem ativamente na prevenção de desastres e na resiliência urbana.

---

## ✨ Principais Funcionalidades
* **Chat Inteligente & Apoio Comunitário:** Conversas em tempo real com a Sarah, instruída para atuar com empatia, acolhimento e precisão técnica nas demandas do Sebinho.
* **Painel de Radar & Telemetria:** Aba dedicada com dados de monitoramento hídrico participativo do Rio Sarapuí e status operacional das estações locais.
* **Chips de Sugestão Rápida:** Atalhos de um toque para perguntas frequentes (status do rio, telefones úteis, protocolos do Cidadão Sensor).
* **Comando por Voz:** Suporte a entrada por microfone para facilitar relatos e registros rápidos em campo.
* **Barra de Emergência Permanente:** Acesso imediato aos telefones da Defesa Civil (**199**) e do **CRAS Rocha Sobrinho**.
* **Pronto para Instalação (PWA):** Manifesto e suporte a instalação direta na tela inicial de smartphones Android.
* **Segurança e Privacidade (LGPD):** Configuração segura da chave de API do Google AI Studio (`AIza...`), armazenada exclusivamente no navegador do usuário (`localStorage`).

---

## 🛠️ Tecnologias Utilizadas
* **Frontend:** HTML5, Tailwind CSS (via CDN).
* **Inteligência Artificial:** Google Gemini API (`gemini-3.6-flash`).
* **Arquitetura:** PWA (Progressive Web App) em arquivo único (`index.html`) para fácil implantação, compartilhamento e atualização contínua.

---

## 📲 Como Usar e Configurar
1. Abra o arquivo `index.html` ou acesse o link publicado do aplicativo no navegador do seu smartphone.
2. Ao abrir pela primeira vez, insira sua chave de API do Google AI Studio clicando no botão **🔑 Chave** no topo.
3. Utilize a navegação para alternar entre o **Chat Inteligente** e o **Radar & Telemetria** do Projeto Cidadão Sensor.
