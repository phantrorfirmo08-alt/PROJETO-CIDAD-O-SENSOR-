Sarah - Assistente Técnico de Defesa Civil Comunitária (Sebinho)
Uma aplicação web leve, interativa e de arquivo único (index.html) desenvolvida para apoiar a gestão de riscos, monitoramento e orientações técnicas de Defesa Civil na Comunidade Sebinho (também conhecida como Maria Cristina), no bairro Rocha Sobrinho, Mesquita, Rio de Janeiro. A ferramenta utiliza o modelo Gemini 3.6 Flash para fornecer orientações preventivas focadas nas vulnerabilidades locais.  
📍 Escopo Geográfico e Operacional
Rua Amazonas: Leito do rio.  
Ponte de Entrada: Ponto crítico de monitoramento da comunidade.  
Confluência: Encontro do Rio Dona Eugênia com o Rio Sarapuí.  
Linha Férrea: Extensão da calha fiscalizada.  
🚀 Funcionalidades
Interface de Chat Integrada: Visual limpo, responsivo e adaptado para dispositivos móveis.  
Indicador Visual de Atividade: Animação de avatar que indica o processamento e a fala da assistente.  
Gerenciamento de Chave API: Armazenamento seguro via localStorage para evitar re-inserções constantes.  
Prompt Especializado Incorporado: Focado em diretrizes rígidas de prevenção de desastres e mitigação de inundações.  
🛠️ Tecnologias Utilizadas
HTML5 & CSS3 com suporte a modo escuro nativo.  
JavaScript (Vanilla / ES6+) para comunicação assíncrona via API.  
Google Gemini API (gemini-3.6-flash).  
📋 Como Usar
Abra o arquivo index.html em qualquer navegador web moderno.  
Insira sua Chave de API do Gemini no campo correspondente e clique em "Salvar Chave".  
Digite sua pergunta, dúvida técnica ou reporte de risco no campo de texto e pressione Enter ou "Enviar".
