README — Sarah IA

## 1. Sobre o projeto

A **Sarah IA** é uma aplicação web comunitária voltada para informação, orientação e monitoramento de condições climáticas.

O projeto foi desenvolvido para funcionar em navegadores modernos, celulares e computadores. Ele também possui estrutura para ser instalado como aplicativo por meio de uma **PWA — Progressive Web App**.

A aplicação reúne:

- Chat comunitário.
- Respostas automáticas.
- Microfone para entrada de voz.
- Respostas faladas.
- Avatar animado da Sarah.
- Olhos piscando.
- Monitoramento de chuva.
- Monitoramento estimado da vazão do rio.
- Gráficos atualizados por API.
- Registro local de ocorrências.
- Compartilhamento do aplicativo.
- Botão de instalação.
- Tema claro e escuro.
- Aumento do tamanho da fonte.
- Consentimento de privacidade.
- Cache offline básico.
- Estrutura compatível com GitHub Pages.
