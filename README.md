Sarah | Assistente Inteligente & Monitor GOES-19
​Aplicação web em arquitetura Single Page Application (SPA) que integra a assistente inteligente Sarah com painéis de telemetria e monitoramento em tempo real do satélite GOES-19, desenvolvida com conformidade à LGPD.
​🚀 Funcionalidades Principais
​Interface Dinâmica da Sarah: Assistente virtual com animações vetoriais, suporte a modo de raciocínio avançado e histórico de conversas interativo.
​Painel Satelital GOES-19: Monitoramento com simulação de varredura radar (ABI Band 13 - IR) e telemetria de link em tempo real.
​Conformidade com a LGPD: Modal de boas-vindas estruturado com os 4 pilares fundamentais (Transparência Absoluta, Minimização de Dados, Segurança Criptografada e Controle do Usuário).
​Design Responsivo & Moderno: Construído com Tailwind CSS e fontes tipográficas Plus Jakarta Sans, utilizando paleta escurecida otimizada para operações contínuas.
​🛠️ Tecnologias Utilizadas
​HTML5 & JavaScript (ES6+)
​Tailwind CSS (via CDN com configuração customizada de tema escuro)
​Google Fonts (Plus Jakarta Sans)
​SVG Animado para avatares e simulações de radar
​📦 Como Executar o Projeto
​Baixe ou salve o código fonte consolidado como index.html em sua máquina.
​Certifique-se de estar conectado à internet (para carregar o Tailwind CSS e as fontes do Google Fonts).
​Dê um duplo clique no arquivo index.html para abri-lo diretamente em qualquer navegador moderno (Chrome, Firefox, Edge, Safari).
