​🚀 O que é?
​Aplicativo PWA de arquivo único para monitoramento climático, telemetria da Bacia do Sarapuí e apoio comunitário (Projeto Cidadão Sensor).
​✨ Funcionalidades
​🤖 Avatar Animado: Robô roxo com piscar sincronizado (robot-eye).
​📡 Telemetria 24h: Níveis hídricos locais (Rocha Sobrinho e Sebinho).
​💬 Assistente IA: Chat integrado (modo local ou via chave Google Gemini).
​🚨 Emergência Rápida: Acesso direto ao 199 e contatos úteis.
​📲 PWA Nativo: Instalação direta pelo Chrome com ícone e tela cheia.
​📲 Como Instalar
​Salve o código como index.html no seu celular.
​Abra o arquivo no Google Chrome.
​Toque em 📲 Instalar no topo (ou vá no menu de três pontos do Chrome e selecione "Adicionar à tela inicial").
​⚠️ Em caso de alerta severo ou risco iminente, priorize sempre a evacuação e ligue para o 199.
