Cidadão Censor - Sarah V4 Core
Sistema independente de monitoramento meteorológico, alerta de riscos e infraestrutura voltado para a Comunidade Sebinho (Rocha Sobrinho, Mesquita - RJ) e Bacia do Sarapuí.
Sobre o Projeto
Plataforma cívica e de Defesa Civil desenvolvida para apoiar o grupo comunitário A Chave da Esperança, integrando telemetria em tempo real, georreferenciamento de riscos e um assistente inteligente autônomo (Sarah V4 Core).
Funcionalidades
Monitoramento Meteorológico: Integração com Open-Meteo para rastreamento de temperatura, umidade e precipitação.
Radar de Tempestades: Sistema de alerta antecipado para núcleos de chuva na região de Mesquita e Bacia do Sarapuí (raio de 2 a 5 km).
Assistente Sarah V4 Core: Interação via chat e comando de voz para suporte técnico, cívico e de infraestrutura.
Geolocalização: Mapeamento interativo via Leaflet da comunidade e pontos de atenção urbana.
Acessibilidade: Suporte nativo a VLibras e redimensionamento dinâmico de fontes.
Como Usar & Baixar o Aplicativo
Acesse o Link: Abra o link oficial da plataforma enviado pelo grupo ou compartilhado no WhatsApp.
Abre Direto no Navegador: O sistema roda direto no navegador do celular ou computador, sem precisar baixar arquivos manualmente na memória.
Instale como App (PWA): Ao abrir o link no celular, utilize a opção do navegador para "Adicionar à Tela Inicial" ou "Instalar Aplicativo" para criar o ícone direto no seu dispositivo como um aplicativo nativo.
Configuração Opcional: Insira sua chave da API do Google AI Studio no campo superior, caso queira habilitar o fluxo completo de respostas dinâmicas avançadas do motor Gemini.
Tecnologias Utilizadas
HTML5 & Tailwind CSS (via CDN)
JavaScript Moderno (Vanilla)
Open-Meteo API & Google Gemini AI API
Leaflet.js para mapas interativos
VLibras para acessibilidade em Libras
Governança & Autonomia
Desenvolvido para uso comunitário, transparência cívica e fomento à resiliência urbana na Comunidade Sebinho, Mesquita, Rio de Janeiro.
