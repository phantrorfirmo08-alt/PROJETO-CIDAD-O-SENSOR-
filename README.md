## 📋 SOBRE O PROJETO

O **Sarah Intelligence Framework v4** é uma Progressive Web App (PWA) de alta performance projetada para atuar como agente meteorológico digital, central de alertas de Defesa Civil e ferramenta de engajamento comunitário. Desenvolvido para apoiar o grupo **A Chave da Esperança**, o sistema integra telemetria em tempo real, mapeamento georreferenciado e inteligência artificial para mitigar riscos de inundação e deslizamento.

---

## ✨ PRINCIPAIS FUNCIONALIDADES

* **🛰️ Monitoramento GOES-19:** Conexão com dados meteorológicos e satelitais para rastreio de precipitação, umidade e ventos na bacia local.
* **🗺️ Mapeamento Interativo (Leaflet):** Visualização georreferenciada centrada na Comunidade Sebinho e no Rio Sarapuí, com raio de monitoramento de risco.
* **🚨 Sistema de Alerta Sonoro e Visual:** Simulação e disparos automáticos para Alerta Amarelo e Vermelho com sirenes sintéticas via Web Audio API.
* **🤖 Assistente de IA Integrado:** Suporte a chaves do Google AI Studio (Gemini API) para consultas sobre urbanismo, leis, Cidades Resilientes (ONU-Habitat) e Periferia Viva.
* **🔊 Acessibilidade & Voz:** Leitor de texto humanizado (`SpeechSynthesis`) em português do Brasil e redimensionamento dinâmico de fontes.
* **🛡️ Governança & LGPD:** Termos de responsabilidade integrados alinhados à Lei Federal nº 13.709/2018 e aos Quatro Pilares de Governança Cívica.
* **📱 Instalação PWA:** Pronto para instalação direta na tela inicial de dispositivos móveis (como o ecossistema Xiaomi/Android).

---

## 🛠️ TECNOLOGIAS UTILIZADAS

* **Frontend:** HTML5, CSS3, Tailwind CSS (via CDN)
* **Mapeamento:** Leaflet.js & OpenStreetMap
* **APIs Externas:** Open-Meteo Weather API & Google Generative Language API (Gemini)
* **Áudio & Síntese:** Web Audio API & Native Speech Synthesis
* **Armazenamento:** LocalStorage (para credenciais de API e aceite de termos)

## 🚀 COMO EXECUTAR O PROJETO

1. Baixe ou clone este repositório em sua máquina.
2. Certifique-se de que o arquivo principal está salvo como `index.html`.
3. Abra o arquivo diretamente em qualquer navegador moderno (Google Chrome, Microsoft Edge ou Safari).
4. Para utilizar as consultas avançadas de Inteligência Artificial, clique no ícone de chave (**🔑**) no cabeçalho e insira sua chave do **Google AI Studio (Gemini)**.
